## The per-step pipeline (every step, strictly in plan order, one step at a time)

1. **BUILD agent** — implements the step per its `shmup_plan.md` section, the Definition of done (§1.3) and the
   conventions (§1.5). Owns working code, the minimum tests its acceptance list names, green CI, and TSDoc on new
   exports. If the plan is wrong or contradicts the code, it makes the smallest sensible adaptation and records it
   under the step in `shmup_plan.md` as **"As built:"** notes; if the step truly cannot be done, it returns
   `blocked`.
2. **REVIEW → FIX loop** — a fresh REVIEW agent reviews all of the step's work (reads the code, runs the full
   check suite). It reports **only must-fix findings** (bugs, spec/acceptance gaps, failing checks, Chromium 69
   incompatibility, determinism/allocation violations, security, clearly bug-prone structure, wrong scripts/docs
   that exist) — never style nits, optional ideas, missing docs/tests, or out-of-scope items. It never edits or
   commits. If it returns findings, a fresh FIX agent fixes them (or declines with a concrete reason), then a
   **new** REVIEW agent looks everything over again. The loop ends when a review returns **zero findings**
   (cap: 5 rounds; if the cap is hit, continue and record `done (review capped)`).
3. **TEST agent** — builds out thorough Vitest suites for the step (unit, edge cases, regression tests for fixed
   findings, integration/e2e/golden where the plan's toolbox §1.4 applies); fixes genuine bugs it finds.
4. **DOCS agent** — complete TSDoc docblocks on everything the step touched (plus module comments and
   `moduleInfo`/Public API sections), client docs in `docs/client/*.md`, developer docs in `docs/dev/*.md`
   (incl. `api-reference.md`), `docs/README.md` index, package READMEs, and the root `README.md` status; then marks
   the step in `shmup_progress.md`.
5. **CI GATE agent** — waits for the GitHub Actions run of the latest `master` commit; if red, diagnoses
   (`gh run view --log-failed`), fixes, pushes and waits again (max 3 attempts). If CI cannot be made green, the
   batch **stops** — never build the next step on a red `master`.

**Every agent that changes files commits and pushes directly to `master` at the end of its job** (no branches, no
PRs — this is my explicit instruction), following the git protocol embedded in the workflow script below.

## Preflight (do this yourself, inline, before the first batch)

1. `git status` must be clean apart from ignored files; `git pull --rebase origin master`.
2. `node -v` (≥ 24.15 or 22.22.2+) and `pnpm -v` (must be 12.x; if not, `npm i -g pnpm@latest`).
3. `pnpm install --frozen-lockfile`, then `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build`
   (and `pnpm test:e2e` once it exists — if Playwright's browser is missing run `pnpm exec playwright install
   chromium`). Also `cd tools/input-probe && npm ci && npm run verify`.
4. CI: `gh run list --branch master --limit 3`. If the latest run is red (or anything in step 3 fails), launch a
   single fix agent (via the Agent tool) to make it green and push before starting any step.
5. `shmup_progress.md`: if missing, create it from the plan's step headings — a table
   `| Step | Title | Status | Review rounds | Tests | Commits | Notes |` with every step `pending`. Set the plan's
   status line (top of `shmup_plan.md`) to **approved — executing** with today's date. Commit and push both
   (`Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` trailer).
6. Build the work list: steps in plan order, within SCOPE, whose status is not `done`/`done (review capped)`.
   A step marked `blocked` is **not** retried automatically — report it and stop.

## Running batches

- Run **one Workflow per milestone** (the not-done steps of the current milestone), using the script below —
  pass it inline via `script` the first time, then re-use the persisted `scriptPath` for later batches, with
  `args = { steps: [{ id, title }, …], maxRounds: 5 }`.
- While a batch runs, don't duplicate its work; wait for the completion notification (I can watch via `/workflows`).
- If a batch is interrupted, relaunch it with `resumeFromRunId` (completed agents replay from cache).
- After each batch:
  1. Read the result (and `journal.jsonl` if anything looks off). Verify with `git log --oneline`, `shmup_progress.md`
     and `gh run list --branch master --limit 3` that every finished step is on `master` and CI is green.
  2. Remove leftover agent worktrees if any exist (`git worktree list`; only remove ones whose HEAD is already on
     `origin/master` and that have no uncommitted changes; delete their `worktree-*` branches).
  3. Give me a short report: steps done, review rounds per step, capped reviews, test counts, bugs found by test
     agents, any "As built" deviations, and — at milestone end — the on-device checklist from plan §8.
  4. If the batch stopped (blocked step or red CI), stop and tell me why. Otherwise continue with the next
     milestone (or pause, per PAUSE_BETWEEN_MILESTONES).
- When SCOPE is complete, give a final summary and suggest the next manual actions (deploy to the M7 monitors from
  the Windows desktop per `docs/client/install-on-tv.md`, run the plan §8 checks).

````js
function header(s) {
  return `# Step ${s.id} — ${s.title}\nYour step's specification is the "### ${s.id} — ${s.title}" section of shmup_plan.md. Read it in full before doing anything.\n`

const buildPrompt = s => `You are the BUILD agent for this step of the Shmup Cup plan.\n\n${header(s)}${CONTEXT}
## Your job
Run the git protocol "Start" command. Implement the step completely and correctly per its plan section, the
Definition of done and the conventions (no TODO stubs for required behavior). Stay within the step's scope. Write the
tests its acceptance criteria name and TSDoc on the exports you add. Run the full check suite and make it green.
If the plan is wrong or contradicts the existing code, make the smallest sensible adaptation and record it under the
step's section in shmup_plan.md as "As built:" bullet notes. Only if the step genuinely cannot be completed, do the
sensible part, record why, and return blocked=true. Commit and push per the git protocol.`

function reviewPrompt(s, round, history) {
  const hist = history.length
    ? `\n## Previous review rounds for this step\n${JSON.stringify(history, null, 2)}\nVerify that items marked "fixed" really are fixed. Do not re-report items marked "declined" unless you have concrete evidence they cause a real defect.\n`
    : ''
  return `You are REVIEW agent (round ${round}) for this step of the Shmup Cup plan.\n\n${header(s)}${CONTEXT}${hist}
## Your job
Run the git protocol "Start" command. Review ALL work done for this step so far: find its commits (git log / git show)
and read the resulting code in full, not just diffs. Check it against the step's plan section, its acceptance
criteria, the Definition of done and the conventions. Actually run the full check suite.

Report ONLY must-fix findings: bugs or incorrect behavior; plan/acceptance requirements missing or wrong; failing
checks; Chromium 69 incompatibility in shipped code; determinism or zero-allocation violations; security problems;
structure that will clearly cause bugs; scripts/instructions that exist but are wrong.
Do NOT report: style nits, subjective preferences, optional enhancements, missing docblocks/docs or missing tests
(later agents handle those), or anything outside this step's scope.
Do NOT modify files and do NOT commit. If nothing is must-fix, return an EMPTY findings array.`
}

const fixPrompt = (s, findings, round) => `You are the FIX agent (after review round ${round}) for this step of the Shmup Cup plan.\n\n${header(s)}${CONTEXT}
## Findings to address
${JSON.stringify(findings, null, 2)}

## Your job
Run the git protocol "Start" command. For each finding: verify it, then fix the root cause. If a finding is wrong or
not applicable, decline it with a concrete explanation. Run the full check suite and make it green. Commit and push
per the git protocol. Return one outcome per finding.`

function testPrompt(s, history) {
  const regress = history.length ? `\n## Issues fixed during review (add regression tests where applicable)\n${JSON.stringify(history, null, 2)}\n` : ''
  return `You are the TEST agent for this step of the Shmup Cup plan.\n\n${header(s)}${CONTEXT}${regress}
## Your job
Run the git protocol "Start" command, then build out a thorough automated test suite for this step's code: unit tests

Wire them into the existing test scripts. If a test reveals a genuine bug, fix the code minimally and list it in
bugsFixed. The full check suite must be green. Commit and push per the git protocol.`
}

const ciPrompt = s => `You are the CI GATE agent after step ${s.id} (${s.title}) of the Shmup Cup plan.\n${CONTEXT}
## Your job
Run the git protocol "Start" command. Find the GitHub Actions CI run for the current HEAD of origin/master
(gh run list --branch master --limit 5 --json databaseId,headSha,status,conclusion,url) and wait for it
(gh run watch <id> --exit-status). Note that CI cancels superseded runs on master — always judge the run for the
latest commit. If it is green, return green=true without changing anything. If it fails, read the failure
(gh run view <id> --log-failed), reproduce locally, fix the root cause, run the full check suite, commit and push per
the git protocol, and wait for the new run. At most 3 fix attempts; if CI still is not green, return green=false with a
precise diagnosis.`

async function call(prompt, opts) {
  const r = await agent(prompt, opts)
  if (r) return r
  log(`${opts.label}: agent returned nothing — retrying once`)
  return agent(prompt, opts)
}

async function runStep(s) {
  const o = (label, schema) => ({ label: `${s.id}:${label}`, phase: s.id, schema })
  const record = { id: s.id, title: s.title, commits: [], rounds: 0, clean: false, history: [] }

  const build = await call(buildPrompt(s), o('build', BUILD_SCHEMA))
  if (build && build.commit) record.commits.push(build.commit)
  record.asBuilt = build ? build.asBuilt || [] : []
  if (!build) return { ...record, stop: true, stopReason: 'build agent failed twice' }
  if (build.blocked) return { ...record, stop: true, stopReason: `blocked: ${build.blockedReason || 'no reason given'}` }
  log(`${s.id}: build pushed ${build.commit || '(no sha)'}`)

  while (record.rounds < MAX_ROUNDS) {
    record.rounds++
    const review = await call(reviewPrompt(s, record.rounds, record.history), o(`review${record.rounds}`, REVIEW_SCHEMA))
    if (!review) { log(`${s.id}: review round ${record.rounds} failed`); continue }
    const findings = review.findings || []
    if (!findings.length) { record.clean = true; log(`${s.id}: review round ${record.rounds} clean`); break }
    log(`${s.id}: review round ${record.rounds} → ${findings.length} must-fix finding(s)`)
    const fix = await call(fixPrompt(s, findings, record.rounds), o(`fix${record.rounds}`, FIX_SCHEMA))
    if (fix && fix.commit) record.commits.push(fix.commit)
    record.history.push({
      round: record.rounds,
      findings: findings.map(f => ({ severity: f.severity, file: f.file, title: f.title })),
      outcomes: fix ? fix.outcomes : [{ title: 'fix agent failed', status: 'declined', note: 'no fix applied' }],
    })
  }
  if (!record.clean) log(`${s.id}: review loop hit the ${MAX_ROUNDS}-round cap — continuing (recorded as review capped)`)

  const tests = await call(testPrompt(s, record.history), o('tests', TEST_SCHEMA))
  if (tests && tests.commit) record.commits.push(tests.commit)
  record.tests = tests ? { count: tests.testCount, allPassing: tests.allPassing, bugsFixed: tests.bugsFixed || [] } : null
  log(`${s.id}: tests ${tests ? `${tests.testCount || '?'} tests, allPassing=${tests.allPassing}` : 'agent failed'}`)

  const docs = await call(docsPrompt(s, record), o('docs', DOCS_SCHEMA))
  if (docs && docs.commit) record.commits.push(docs.commit)
  log(`${s.id}: docs ${docs ? 'pushed' : 'agent failed'}`)

  const ci = await call(ciPrompt(s), o('ci', CI_SCHEMA))
  record.ci = ci ? { green: ci.green, attempts: ci.attempts, url: ci.runUrl, summary: ci.summary } : null
  if (!ci || !ci.green) return { ...record, stop: true, stopReason: `CI not green after ${s.id}: ${ci ? ci.summary : 'CI gate agent failed'}` }
  log(`${s.id}: CI green — step complete`)
  return record
}

const results = []
for (const s of STEPS) {
  const r = await runStep(s)
  results.push(r)
  if (r.stop) { log(`STOPPING after ${s.id}: ${r.stopReason}`); break }
}
return { completed: results.filter(r => !r.stop).map(r => r.id), stopped: results.find(r => r.stop) || null, results }
````
